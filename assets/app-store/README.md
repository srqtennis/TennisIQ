# App Store screenshots

Actual simulator captures of the updated native app, with the approved brand mark and clean status bar.

- `iphone/01-home.png`: 1320 × 2868, iPhone 18 Pro Max.
- `ipad/01-home.png`: 2064 × 2752, iPad Pro 13-inch (M5).

These dimensions match Apple's 6.9-inch iPhone and 13-inch iPad screenshot slots: https://developer.apple.com/help/app-store-connect/reference/app-information/screenshot-specifications

Starter screenshots only: home screen on each supported device family. Additional quiz and explanation captures would better show gameplay. Nothing uploaded to App Store Connect.

The simulator build succeeded and its Info.plist includes AppIcon as the primary icon. The source icon is 1024 × 1024 with no alpha channel. Signing, privacy preparation, real-device testing and store submission remain separate release steps.
